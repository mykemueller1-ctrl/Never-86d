Based on the provided video demonstration of the PDQ POS system, here are the extracted operational details:

**Ringing Up Orders**
*   **Phone Orders:** Touching a returning customer's name automatically brings up their address and information. Pressing the "Place Order" arrow starts the order. The system displays customer history, including the last/first call dates, average check amount, and total number of calls. After selecting items, hitting "Send" and choosing "Delivery" provides an order recap and estimated time.
*   **Counter/Walk-in Orders:** There is no need to select a customer or phone button. The user can immediately start selecting menu items. Hitting "Pay" transitions the screen to a cash register interface to enter the tendered amount, calculate change, and open the cash drawer.
*   **Add to an Existing Order:** Touching the check number next to a customer's name on the main screen recalls their order. Selecting "Open Check" allows the user to add new items and resend the order to the kitchen.
*   **Recalling Pickup Orders:** Pressing "Recall Check" displays a list of all available pickup orders. Touching a customer's name brings up their check to process payment via the cash register interface, with an option to print a receipt.
*   **Separate Orders (Group Orders):** For multiple people ordering under one delivery, the user selects items for the first person, hits "Sub Total," types in their name, and hits "Save." This process is repeated for each person. The user can toggle between names to view individual sub-orders. When sent, the recap shows the total for each specific person.

**Menu Navigation & Modifiers**
*   **Navigation:** The menu is categorized by item types (e.g., Pizza, Gourmet Pizza, Hoagies, Salads).
*   **Modifiers:** Users can easily add or remove ingredients (e.g., "No Lettuce," "Extra Mayo").
*   **Price-Leveled Toppings:** When ordering items like pizza, toppings are price-leveled, meaning the system automatically charges the correct amount based on the size of the pizza selected.
*   **Forced Modifiers:** For certain items, like salads, the system forces a modifier selection (e.g., choosing a dressing or "No Dressing"). A prompt stating "You must make 1 selection" appears, ensuring the kitchen receives a complete order without needing to ask questions.

**Delivery Features**
*   **Driver Dispatch Screen:** This screen displays all in-house orders waiting for delivery, the address, how long ago the order was placed, drivers currently out, and available drivers. Late deliveries are highlighted in yellow.
*   **Assigning Deliveries:** Deliveries are assigned by touching the order(s) and then touching an available driver's name.
*   **Driver Reminders:** When assigning an order, the system may pop up a "Don't Forget These Items" screen, reminding the driver to collect specific items like sodas.
*   **Checking Order Status:** Touching an active ticket on the main screen shows its status, including the exact time it was assigned and to which driver.
*   **Mapping and Directions:** From the dispatch screen, a "Map" button displays a visual map showing the store's location (blue pin) and the delivery destinations (green pins). A "Directions" button provides printable, turn-by-turn street directions with distances and estimated driving times.

**Reporting & Manager Functions**
*   **Manager Overrides/Access:** Accessing manager features requires entering an Employee ID and a Password.
*   **Driver Reports (End of Shift):** Under "Driver Functions," the system lists every active driver and calculates their end-of-shift totals. It displays the quantity of orders, total sales, cash drops, banks, driver reimbursements (DMR), paid outs, charge tips, and the final balance the driver owes the store, allowing for a checkout process that takes seconds.
