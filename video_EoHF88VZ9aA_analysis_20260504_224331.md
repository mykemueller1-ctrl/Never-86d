Based on the provided video demonstration, here is a detailed extraction of all the PDQ POS system operations shown:

**1. Phone Order**
*   **Customer Selection:** Touching a caller's name on the left-hand panel automatically brings up their customer and address information.
*   **Order History:** Pressing the green "Place Order" arrow displays the customer's order history, including the dates of their first and last calls, average check amount, and total number of calls.
*   **Menu Navigation & Modifiers:** The user navigates category tabs (e.g., Pizza) and selects items (e.g., Large 16", Medium 14", Personal 10"). Modifiers (toppings like Pepperoni, Mushrooms, Sausage) are selected, and the system automatically price-levels them based on the size of the pizza.
*   **Sending the Order:** Pressing "Send" brings up order type options. Selecting "Delivery" shows a recap screen with the total, and "Send Order" finalizes it.

**2. Pick Up Order**
*   **Menu Navigation & Modifiers:** Similar to phone orders, items are selected from categories (e.g., Hoagies -> Turkey). Modifiers can be added or removed (e.g., Onions, Tomatoes, No Lettuce, Extra Mayo).
*   **Forced Modifiers:** When selecting certain items, like a Salad, the system forces the user to make a selection (e.g., choosing a dressing or "No Dressing") before proceeding, ensuring the kitchen has all necessary information.
*   **Sending the Order:** The order is sent and designated as a "Pickup".

**3. Counter Order**
*   **Direct Entry:** For walk-in customers, there is no need to select a customer profile. Items are entered directly from the menu screen.
*   **Payment Processing:** Pressing "Pay" turns the screen into a cash register interface. The user enters the tendered amount (e.g., $20.00 for a $9.81 balance), and the system calculates the change due and opens the cash drawer.

**4. Add to an Existing Order**
*   **Recalling an Order:** Touching the check number next to an active caller's name opens their current order.
*   **Modifying:** Pressing "Open Check" allows the user to add new items (e.g., Wings with Hot Sauce) to the existing order. The updated order is then re-sent for delivery.

**5. Pick Up Order Completion**
*   **Recalling Pickups:** Pressing the "Recall" button brings up a list of all pending pickup orders, identifiable by name or phone number.
*   **Settling the Bill:** Selecting an order brings up the payment screen. The user presses "Pay Balance," enters the tendered amount, and the system calculates change. There is an option to "Print Ticket" for a receipt.

**6. Separate Orders (Sub-totals)**
*   **Creating Sub-orders:** When a single caller is placing an order for multiple people, the user can ring up an item, press "Sub Total," and type in a name for that specific portion of the order (e.g., "Agnes").
*   **Managing Multiple Names:** This process is repeated for each person. The system creates tabs at the bottom of the screen to easily switch between the different sub-orders.
*   **Finalizing:** When sent for delivery, the recap screen breaks down the total cost for each individual person on the order.

**7. Delivery Features & Dispatch**
*   **Driver Dispatch Screen:** Pressing the "Dispatch" button shows all in-house orders waiting for delivery (including address and wait time) and a list of available drivers.
*   **Assigning Deliveries:** The user touches the order(s) and then touches a driver's name to assign them. The driver is then moved to the "Out" column.
*   **Late Warnings:** The system color-codes orders (e.g., yellow) to indicate if a delivery is running late.
*   **Item Reminders:** When assigning an order, a pop-up screen reminds the driver of specific items they need to physically gather, such as sodas or chips.
*   **Checking Order Status:** Touching a check number on the main screen provides the status of the order, including which driver it was assigned to and at what time.

**8. Driver Mapping**
*   **Visual Map:** From the dispatch screen, pressing "Map" displays a map showing the store's location and the locations of pending deliveries.
*   **Turn-by-Turn Directions:** Pressing the "Directions" button provides a detailed, printable list of street-by-street driving instructions.

**9. Driver Reports & End of Shift**
*   **Manager Access:** Pressing "Manager" requires a PIN to access restricted functions.
*   **Driver Settlement:** Selecting "Driver Functions" brings up a comprehensive report for all drivers. It details the number of orders taken, total sales, any cash drops made during the shift, starting banks, reimbursements, and the final balance the driver owes the store. This allows for quick cash settlement at the end of a driver's shift.

*(Note: Voids, discounts, and specific manager overrides were not explicitly demonstrated in this video segment.)*
